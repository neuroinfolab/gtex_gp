# Traceability Map: `main(3).tex` -> Code + Artifacts

This note links manuscript content in `docs/manuscript/main(3).tex` to code paths that generate model outputs, diagnostics, and figures.

## Canonical workflow entrypoint

- Notebook/CLI workflow:
  - `notebooks/ahba_gtex_writeup_end_to_end.py`
  - `scripts/run_writeup_workflow.py`
  - `src/workflows/writeup_pipeline.py`

The full orchestration in `run_writeup_workflow(...)` is:
1. `load_dataset_bundle(...)`
2. `summarize_shared_harmonization(...)`
3. `run_naive_fill(...)`
4. `run_dlam(...)`
5. `run_plam(...)`
6. `run_allgene_loro(...)`
7. `select_representative_subject(...)`
8. `build_manuscript_assets(...)`
9. `write_run_manifest(...)`

## Methods section provenance

### Harmonization (ComBat)

- Manuscript section: Cross-Dataset Harmonization
- Implementation:
  - `src/harmonize/combat.py` (`CombatHarmonizer.fit`, `.transform`)
  - registry entrypoint: `src/harmonize/__init__.py` (`fit_harmonizer(..., method="combat", ...)`)
- Workflow usage:
  - shared harmonization summary: `src/workflows/writeup_pipeline.py` -> `_shared_harmonized(...)`
  - reused in all model/eval stages.

### Naive atlas-fill baseline

- Manuscript section: Naive Atlas-Fill Baseline
- Implementation:
  - `src/workflows/writeup_pipeline.py` -> `run_naive_fill(...)`
- Behavior:
  - keeps observed GTEx parcels,
  - fills unobserved parcels from harmonized AHBA atlas.

### DLAM (deterministic latent alignment)

- Manuscript section: Deterministic Latent Alignment Model
- Core implementation:
  - `src/models/baseline_pipeline.py` -> `run_subject(...)`
  - `src/latent/pls.py` -> `fit_subject_pls(...)`
  - `src/latent/basis_maps.py` -> affine/orthogonal latent map fitting
  - `src/spatial/rbf.py` and `src/spatial/gp.py` -> latent spatial completion
- Workflow wrapper:
  - `src/workflows/writeup_pipeline.py` -> `run_dlam(...)`

### PLAM (probabilistic latent alignment)

- Manuscript section: Probabilistic Latent Alignment Model
- Core implementation:
  - `src/models/unified_generative.py`
    - `UnifiedGenerativeConfig`
    - `fit_global_atlas_unified(...)`
    - `infer_subject_unified(...)`
    - latent updates, Procrustes alignment, GP deviation completion, calibration updates
- Workflow wrapper:
  - `src/workflows/writeup_pipeline.py` -> `run_plam(...)`

### LORO validation protocol

- Manuscript section: Validation Context
- Core evaluation logic:
  - `scripts/build_dual_model_loro_metric_panels.py`
  - `src/eval/loro.py` (general LORO utility)
- Workflow callsite:
  - `src/workflows/writeup_pipeline.py` -> `run_allgene_loro(...)` (invokes script above).
