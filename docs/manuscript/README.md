# Manuscript Source

- `main.tex` is the current manuscript source tracked in the repository.
- `figs/` and `tables/` are generated by the notebook-first workflow and are ignored by Git except for placeholder files.
- `parcel_matching.md` is the formal GTEx-to-AHBA parcel matching policy used to document coordinate matching, cortical/cerebellar overrides, and subcortical manual validation. See `../../parcel_assignment.ipynb` for the companion exploratory notebook.
- `expression_harmonization.md` is the formal AHBA-GTEx harmonization procedure used to document the ComBat-style correction, covariates, AHBA-referenced GTEx affine calibration, LORO/PREPOST fit semantics, and caveats.

To regenerate manuscript-facing assets without compiling the paper:

```bash
python3 scripts/run_writeup_workflow.py --config configs/notebook_full.yaml
```
